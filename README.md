# Real Estate Price Prediction

Система аналізу даних та прогнозування вартості нерухомості на основі характеристик об'єкта.

Проєкт охоплює повний цикл роботи з даними: підготовку та аналіз датасету, навчання моделі машинного навчання, збереження моделі, створення REST API, клієнтського вебінтерфейсу та автоматизованих тестів.

## Основні можливості

Система дозволяє:

- прогнозувати вартість одного об'єкта нерухомості;
- виконувати пакетне прогнозування для декількох об'єктів;
- перевіряти стан API та завантаження моделі;
- отримувати інформацію про ML-модель;
- повторно навчати та зберігати модель;
- використовувати вебінтерфейс Streamlit для введення характеристик нерухомості;
- взаємодіяти з REST API через Jupyter Notebook;
- автоматично перевіряти API та ML-сервіс за допомогою pytest.

## Дані

Після очищення та підготовки даних для моделювання використано:

- 907 414 об'єктів нерухомості;
- 7 вхідних ознак;
- цільову змінну `price`.

Вхідні ознаки:

- `bed` — кількість спалень;
- `bath` — кількість ванних кімнат;
- `house_size` — площа будинку;
- `acre_lot` — площа земельної ділянки;
- `state` — штат;
- `city` — місто;
- `zip_code` — поштовий індекс.

## Machine Learning

Для прогнозування вартості нерухомості використовується модель:

`RandomForestRegressor`

Основні параметри фінальної моделі:

- `n_estimators = 100`
- `max_depth = 20`
- `min_samples_leaf = 2`
- `max_features = 0.8`
- `random_state = 42`

Дані розділено на навчальну та тестову вибірки у співвідношенні 80/20:

- Train: 725 931 об'єкт;
- Test: 181 483 об'єкти.

### Результати моделі

На тестовій вибірці отримано:

| Метрика | Значення |
|---|---:|
| MAE | $185,213.17 |
| RMSE | $710,437.89 |
| R² | 0.7396 |

Для порівняння використовувалась baseline-модель на основі медіанного значення ціни.

| Метрика | Random Forest | Baseline |
|---|---:|---:|
| MAE | $185,213.17 | $402,065.59 |
| RMSE | $710,437.89 | $1,414,481.29 |
| R² | 0.7396 | -0.0324 |

## REST API

FastAPI надає такі endpoint-и:

| Method | Endpoint | Призначення |
|---|---|---|
| GET | `/health` | Перевірка стану API та моделі |
| GET | `/model/info` | Інформація про модель |
| POST | `/predict` | Прогноз для одного об'єкта |
| POST | `/predict/batch` | Пакетне прогнозування |
| POST | `/train` | Повторне навчання моделі |

Swagger-документація після запуску API доступна за адресою:

`http://127.0.0.1:8000/docs`

## Дані та навчена модель

Через великий розмір файлів початковий датасет та навчена ML-модель не зберігаються безпосередньо в GitHub-репозиторії.

Локально проєкт використовує такі файли:

```text
data/raw/realtor-data.csv
data/processed/real_estate_clean.csv
models/real_estate_rf.joblib
```

Початковий датасет використовується для аналізу та підготовки даних. Після очищення формується `real_estate_clean.csv`, який використовується для навчання моделі.

Навчена модель зберігається у:

```text
models/real_estate_rf.joblib
```

Модель можна повторно створити за допомогою `TrainingService` та endpoint-а:

```text
POST /train
```

Навчання виконується на підготовленому датасеті та може потребувати значного часу й обчислювальних ресурсів.

## Запуск проєкту

### 1. Встановлення залежностей

```bash
python -m pip install -r requirements.txt
```

### 2. Запуск FastAPI

З кореневої папки проєкту:

```bash
python -m uvicorn src.api.main:app --reload
```

API буде доступне за адресою:

`http://127.0.0.1:8000`

### 3. Запуск Streamlit

В окремому терміналі:

```bash
python -m streamlit run src/streamlit_app/app.py
```

Після запуску відкриється вебінтерфейс для введення характеристик об'єкта та отримання прогнозованої ціни.

## Тестування

Для запуску всіх автоматизованих тестів:

```bash
python -m pytest tests -v
```

Реалізовано 8 автоматизованих тестів:

- 5 тестів REST API;
- 3 тести `ModelService`.

Перевіряються:

- стан API;
- інформація про модель;
- одиночне прогнозування;
- пакетне прогнозування;
- валідація неправильних даних;
- завантаження ML-моделі;
- прогнозування через `ModelService`.

Поточний результат:

```text
8 passed
```

## Результат

У межах проєкту реалізовано завершений процес прогнозування вартості нерухомості: від підготовки даних і навчання моделі машинного навчання до REST API, вебінтерфейсу та автоматизованого тестування.
